Pawns of War 存档工具

离线 HTML 版 · 不联网 · 不上传 · 支持 POWSAVE1 / POWMIGR1

怎么用（外行也能看）

方法1：

1. 先把存档文件复制到设备能访问的位置，例如 Download；

2. 点下面“选择存档文件”，再点“解包为 JSON”；

3. 在文本框里修改数据；

4. 点“回包并下载”，把下载的文件放回游戏存档位置。

方法2：

1. 先把存档文件复制到设备能访问的位置，例如 Download；

2. 点下面“选择存档文件”，再点“解包为 JSON”；

3. 点“下载 JSON”

4. 用其他软件编辑 JSON 文件；

5. 编辑完成后，点击“导入 JSON”，将 JSON 文件重新导入游戏存档工具。

6. 点“回包并下载”，把下载的文件放回游戏存档位置。

Windows：直接选择存档文件中的 save_file 即可，改完覆盖回去。

Android / iOS：系统限制浏览器不能直接读写游戏沙盒，需要先复制出来、改完再复制回去。
